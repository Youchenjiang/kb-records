## 課堂背景與技術範疇

本堂課為 10/16 資訊安全實務課程的第三節實習操作課。承接第二節課對 picoCTF 靶場與 CyberChef 工具之初步建立，本節課林助教進一步展示 Web 安全領域中最基礎且關鍵的「前端逆向與資訊搜集技術」：

1. **靶機實例連線（Instance Launch）**：點選平臺按鈕啟動獨立的 Web 靶機實例，並建立連線通道。
2. **瀏覽器開發者工具（DevTools / Inspect）三大關鍵分析視角**：
   - **Elements（元素檢視器）**：審查 HTML 結構、表單隱藏欄位（Hidden Input）與開發者遺留之註解文字（Comments）。
   - **Sources（來源檔案）**：檢視與搜尋前端引用的 JavaScript 腳本與 CSS 樣式表，還原未混淆或壓縮之邏輯變數。
   - **Application -> Cookies（應用程式儲存區）**：檢查客戶端儲存的 Session Cookie 與自訂鍵值對，辨識未加密之認證狀態或旗標片段。
3. **自主解題與作業評量規範**：
   - 助教說明後續 4 道挑戰題之探索方向，規範學生非萬不得已「先不看 Hint（題目提示）」，培養獨立逆向直覺。
   - 明確本次實習作業繳交標準：於作業區填報 picoCTF 帳號名稱、完成 6 道題目之通關驗證，並撰寫簡要解題思維分析。
   - 提前完成之進階同學，可自主探索平臺 500+ 道中高階（Medium / Hard）演練題目。

## 課堂完整對話記錄

**【授課教師】**：好，大家看螢幕。一個是你要啟動靶場的網站，對不對？你在畫面上要跟對方的伺服器建立連線，平臺就會幫你啟動一個專屬的靶機實例並做好相關的連線輔助。那第二個動作呢，就是剛才助教說的那個功能叫什麼？Inspect（檢查網頁元素），大家知道嗎？

**【授課教師】**：進入 Inspect 之後，畫面會提示一些關鍵的線索。所以這邊我們要學到、各位今天一定要帶回去的一個重要資安觀念在這裡：我們必須知道，在現代的網頁技術裡面，瀏覽器內建的這些開發者工具，各位以前可能在其他寫網頁的課看過，對不對？但今天從資安滲透的角度出發，你將來對這個工具會更加熟悉，你可以從裡面看到許多過去完全沒有注意到的細節，好不好？

**【授課教師】**：好，大家先跟上來。待會兒各位都跟上、前兩題都完成之後，後面還有四個稍微需要動態思考的練習題。不過在大家正式開始練習之前，我會先請助教跟各位簡單說明一下這四個題目的核心意義，接下來大家再去自行嘗試，好不好？

**【授課教師】**：我們今天最後請各位把握時間做到這裡。現在大家就設法跟著助教剛才的步驟，自己操作一遍。這個動作其實非常快，大概一兩分鐘就能做完，好嗎？

**【林助教】**：好，大家切換一下視窗，這兩題都可以順利開啟。那像是這裡，Inspect 檢視元素的功能，就是讓大家知道可以從哪個方向切入做分析。

**【授課教師】**：對，有些題目它直接說明裡面有隱藏資訊，我們要自己去把它找出來，助教待會兒會為大家認真解答。大家前兩題是不是都完成了？這邊完成了嗎？好，都完成了。

**【授課教師】**：好，前面兩題大家都順利完成了，那剩下的四道題目，老師就請助教跟各位簡單介紹一下解題方向。助教不會直接在投影幕上把答案做出來，只會針對比較特殊的題目給予啟發。比如說平臺上的 Hint（提示），前面題目比較直觀所以不需要，但待會兒如果是你自己解題、沒有人在旁邊示範的時候，如果真的撞牆卡關了，你可以偷偷看一下提示。但是一開始先不要看，好不好？先嘗試自己找線索，最後實在解不出來再去參考。好，請助教為大家簡單說明一下。

**【林助教】**：好的，那我簡單說明一下後續題目的核心方向。前面第一題跟第二題基本上都跟文字編碼與前端展示有關，那後面的四題其實都跟這兩題有很強的相關性。

**【林助教】**：操作步驟是一樣的：首先點選平臺上的按鈕啟動靶機實例（Launch Instance），然後開啟給予的專屬網站連結。連進去之後，我們就直接按右鍵開啟瀏覽器的「檢查（Inspect）」進入開發者工具（DevTools）。

**【林助教】**：在開發者工具裡面，有三個標籤頁是大家要特別注意的：
- 第一個是「Elements（元素）」頁面，除了看一般的排版結構之外，要特別留意 HTML 裡面有沒有隱藏的註解文字（Comments）或者 `style="display:none"` 的隱藏標籤；
- 第二個是「Sources（來源檔案）」標籤頁，我們可以點進去看這個網站載入了哪些 JavaScript 腳本或靜態檔案，直接在來源檔案裡面搜尋關鍵字，很多時候未處理的邏輯或旗標就直接寫在腳本裡面；
- 第三個是切換到「Application（應用程式儲存區）」，在左側選單裡面找到「Cookies」選項，點開目標網站的 Cookie 清單，看一下瀏覽器裡面儲存了哪些鍵值對。有些題目的認證狀態或旗標片段，就直接藏在特定的 Cookie 欄位裡面！

**【林助教】**：主要就是 Elements、Sources 跟 Cookies 這三個地方要特別注意，這就是後續題目最核心的探索方向。

**【授課教師】**：好，助教剛才的提示非常精準！這幾題的目的，就是讓大家第一步先熟悉在 Web 滲透實習中的介面與觀察習慣。各位以後就知道：當你面對一個完全陌生的網頁時，表面上看起來再正常不過，但只要把開發者工具打開，「敲一敲、打一打」，你就知道該從哪裡敲、從哪裡看最能找到脆弱點，好不好？

**【授課教師】**：好，我們給各位差不多十分鐘的時間，大家嘗試在十分鐘內把這四題解出來。非不得已，大家先不要看 Hint！

**【林助教】**：我補充一下作業繳交的說明：做完這六題的同學，可以直接到我們學校的課程作業區進行繳交。繳交的內容包含：第一，填寫你在 picoCTF 平臺上註冊的帳號名稱，讓助教可以在後台 Classroom 確認你確實完成了這六題；第二，簡要回答這六道題目的相關解題思路與觀念。這就是我們這次的實習作業。

**【授課教師】**：好，建議各位都先自己思考解出來之後再去填寫作業，因為作業題目也是給你思考方向的提示。通常你在真實解題時是沒有這種提示優勢的。大家就先照著步驟把字串丟進工具、觀察正常畫面，去試試看！

**【授課教師】**：好，全部做完六題的同學請舉個手……非常好，大部分同學都做完了！做完這六題的同學，現在可以開始瀏覽 picoCTF 平臺上的其他資源了。

**【授課教師】**：平臺上剛剛說過有五百多道題目，大家可以點進 Practice 頁面，看看還有哪些題目類別。剛才助教挑選的都是最基礎的 Easy 等級題目，大家有興趣可以點開 Medium 甚至 Hard 等級的題目看一看。即使現在暫時不會做也沒有關係，先看看國際上的資安競賽都在考什麼樣的題目、要求什麼樣的技能。

**【授課教師】**：好，我們大家繼續操作練習到三點半，老師再做最後的課程總結。大家加油！

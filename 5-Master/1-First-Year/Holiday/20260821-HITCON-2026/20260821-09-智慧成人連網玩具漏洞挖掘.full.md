## ⚡ 閃電秀 6：來自超自然的震動——智慧成人連網玩具漏洞挖掘（S & 艾子）

**【大會主持人】**：感謝第五位講者！接下來第六位壓軸登場——如果大家還記得的話，去年閃電秀有位講者分享了「智慧佛珠」的漏洞挖掘，令人印象非常深刻！今年這位夥伴又帶來了續集，主題是《來自超自然的震動：Bug Hunting》，希望等一下不會有違反 Code of Conduct（COC）的問題（笑）。掌聲歡迎 S 與艾子！

**【S】**：各位安安，原本想說今年不講了，不過有人敲碗希望我講，那我就來分享一下。這是我今年的主題：《來自超自然的震動：Bug Hunting》。我是 S，被朋友笑稱是不務正業的資安研究員；旁邊是我的好友艾子，因為這次發現了一個很有趣的 Target，所以他被我拖下水一起來做這個奇怪的研究。

因為這次研究的產品性質比較特殊，雖然投影片不會有直接露骨的畫面，但產品本身還是屬於成人用品，所以先在這邊聲明「NSFW（Not Safe For Work）」，如果不習慣的會眾可以稍微迴避一下。

去年做完智慧佛珠的研究之後，我一度陷入「我是誰？我在哪裡？我接下來要做什麼？」的迷惘。我開始翻開我自己的研究 Idea 筆記本，思考有什麼好玩的研究可以做。以前做遊戲外掛時研究過 Windows Kernel Driver，成功打到 Crash 過；但硬體研究方面，第一個我很窮買不起昂貴的專業測試設備，第二個大廠大家都在用 AI/GPT 狂砸，我買不起算力；好不容易買到一些設備，又卡在硬體韌體加密讀不出來，動彈不得。

於是我繼續翻筆記本，突然想起來：我以前讀研究所時做過藍牙（BLE）相關的研究！很奇妙的是，國外針對藍牙物聯網的安全研究中，其實有一批專門在探討「特殊成人情趣連網玩具」上的漏洞挖掘！於是我抱著非常認真的研究心態去 Survey：到底市面上哪一款智慧玩具是大家最推薦、最好用、且具備跨國遠端連線功能的？

鎖定目標後，我開始進行 Reconnaissance（資產偵察）。整個系統架構分成三層：手機 App、連網玩具裝置本體，以及雲端中央 Server。裝置與手機 App 之間透過藍牙 BLE 傳輸控制，而 App 具備 Streaming 即時串流、語音、Video 視訊通話、Remote Control 遠端控制，以及加好友社群功能——這就是為什麼我一定要把好友艾子拖下水的原因（笑）！

我們用自動化測試工具進行全面滲透測試，幸運的是我們挖到了非常多的 Bug，目前確認的至少有 6 個漏洞，還有更多正在釐清中。因為時間有限，今天重點講「Session 與身分偽造」的部分：

這款產品支援使用者之間發起雙向視訊與遠端震動互動。正常流程是用戶 A 要跟用戶 B 視訊時，A 向 Server 發送 Request，Server 發送通知給 B 的手機詢問是否接受。但是在我們逆向分析 Protocol 封包後，發現 Session 建立完全是由 Client 端自定義並上傳，雲端 Server 在後續溝通時完全只認 Client 給的 Session ID，而且這個 Session ID 完全可以被任意偽造！

說白一點：攻擊者只要在 App 上的 Public Profile 蒐集目標使用者的公開資訊與 ID，就能在未經授權下偽造目標身分，直接對任意受害者發起視訊連線與遠端裝置控制！

接下來我們要做的是將這些漏洞整理完整向廠商回報漏洞（Responsible Disclosure）。另外更有意思的一點是：我們發現玩具硬體內部的特定暫存器缺乏邊界檢查（Boundary Check），攻擊者有機會透過藍牙發送超額指令讓硬體馬達持續過載、引發過熱甚至燒毀的風險！

不過我們要當個有道德的白帽駭客，絕對不能隨便散播 Exploit。以上是我們今年的分享，謝謝大家！

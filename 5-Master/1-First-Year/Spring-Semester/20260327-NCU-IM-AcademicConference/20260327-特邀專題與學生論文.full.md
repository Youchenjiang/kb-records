## 🛡️ 論文一：DRAVILaMA 對比學習微調 LLM 結合圖結構之 Android 惡意程式抗混淆偵測

**【發表者 沈柏寧】**：歐陽教授好、各位同學好，這是我今天要報告的論文主題——DRAVILaMA：結合對比學習微調大型語言模型（LLM）特徵與圖結構特徵，以提升 Android 惡意程式偵測之抗混淆能力。我將分成研究背景與動機、研究方法、以及實驗結果三大部分進行報告。

首先從背景開始。根據 StatCounter 的統計數據，截至二零二六年二月，在目前全球行動裝置作業系統市場中，Android 以 68.24% 的市佔率高居第一。Android 因為長期維持極高的市場佔有率，容易成為惡意攻擊者的主要目標。攻擊者通常會將惡意行為隱藏在看似正常的應用程式（APK）中，在使用者不經意間竊取隱私資料，例如手機門號、裝置識別碼（IMEI）、定位資訊等。Wang 等人的研究透過 VirusTotal 惡意程式分析工具指出，高達 80% 的 Android 惡意程式皆使用混淆技術（Obfuscation）來規避一般的特徵碼分析與防毒偵測。

現有大部分的 Android 惡意程式偵測方法，都是透過靜態反編譯建構函式呼叫圖（Function Call Graph, FCG）來找出函式之間的相依關係，進而建構圖結構特徵，再利用圖神經網路（GNN）學習惡意行為模式。這種圖結構方法在一般未混淆的情況下，偵測效果非常出色；但若攻擊者使用了能改變圖結構的混淆手法，模型針對混淆後 APK 的偵測效果就會急遽下降。

另一方面，近年大型語言模型（LLM）展現出優異的程式碼閱讀與語意理解能力，能夠理解高階原始碼的語意，理論上能補足純圖結構方法在高階語意理解上的不足。然而，LLM 雖然具備語意理解能力，若未針對混淆情境進行專門微調訓練，其語意表示向量對於混淆改寫（如控制流平坦化、反射呼叫等）會變得極度敏感與脆弱。

因此本研究聚焦於兩大研究缺口：
1. 現有圖結構方法大多依賴 Opcode（操作碼）序列及 Permission（使用權限）特徵，對高階程式碼語意的理解能力有限；
2. 現有 LLM 在 Android 惡意程式偵測任務中，均未針對混淆環境進行對比學習等顯式語意對齊，導致語意表示對混淆變更高度敏感。

本研究目的在於：藉由對比學習訓練 LLM，引導模型學習「語意不變性（Semantic Invariance）」——即程式混淆前後語意特徵的一致性；並結合 LLM 語意特徵與 GNN 圖結構特徵，補足高階語意與結構關係，全面提升混淆情境下的偵測穩定度與準確度。

在混淆手法分析上：
- 重新命名（Rename）：將類別名、函式名或變數名改為無意義字元（如 `deviceInfo` 改為 `A`）。此手法僅改變名稱，執行流程與呼叫依賴關係不變，因此對傳統 FCG 圖結構方法具備抗性；
- 反射呼叫與拆分重構（Reflection / Code Flattening）：例如將發送簡訊等關鍵行為拆分至多個運算函式並以反射機制呼叫，這會徹底改變 FCG 函式呼叫圖的拓撲結構與 Opcode 分佈，導致圖結構偵測方法失效。
- 程式碼克隆與語意不變性：透過對比學習拉近「混淆前與混淆後相同行為程式碼」在嵌入空間中的距離，使模型專注於深層語意而非表面語法結構。

系統架構分為三大模組：
1. **資料處理層**：使用 Obfuscapk 對 APK 資料集注入混淆；利用 Androguard / Apktool 反編譯產出函式呼叫圖（FCG）；以 PSScout 識別呼叫敏感權限的核心 API，擷取其上下兩層鄰近節點構建行為子圖（Behavior Subgraph, BSH/BSS）；並使用 JADX 將行為子圖反編譯為 Java 原始碼；
2. **特徵學習層**：
   - **結構特徵**：由 BSH 節點的 Opcode 與 Permission 特徵輸入 GNN 進行訊息傳遞聚合，經由 Max Pooling 與 Average Pooling 產出結構嵌入向量；
   - **語意特徵**：比對混淆前後受影響的 BSH 子圖原始碼，輸入 CodeLlama 生成語意特徵；使用 Attention Pooling 聚合為全域 APK 語意向量；
   - **對比學習**：將同一 APK 混淆前後之語意向量視為正樣本對，Batch 內其餘 APK 視為負樣本，透過對比損失拉近正樣本、推遠負樣本；
3. **特徵融合與分類**：將訓練完成之 GNN 結構特徵與 CodeLlama 語意特徵進行串接（Concatenation），輸入由雙層 MLP 組成的分類器，完成良性/惡意二元分類判定。

以上是我的報告，謝謝大家！

## ⚡ 論文二：B2B 電力交易市場之公司認證在區塊鏈上的拓展方案

**【大會司儀】**：謝謝歐陽教授。接下來歡迎下一位發表者——張玉瑤同學，發表主題為「B2B 電力量測與交易市場之公司認證在區塊鏈上的拓展方案」。請張同學！

**【發表者 張玉瑤】**：教授好、各位同學好，我是張玉瑤，我的指導教授是葉偉陽博士。今天我要分享的論文主題是「B2B 電力量測與交易市場之公司認證在區塊鏈上的拓展方案」。

隨著再生能源與儲能設備普及，傳統集中式發電正轉向分散式能源架構。在分散式能源架構中，B2B（企業對企業）與 P2P 電力交易成為核心模式。產銷者（Prosumer）利用自發綠電供電，多餘電力則能轉售給其他用電企業以達到能源效益最佳化。然而在去中心化架構下，必須仰賴配電系統運營商（Distribution System Operator, DSO）記錄交易資訊、結算電費與清算市場。

目前分散式電力市場面臨四大挑戰：
1. **隱私洩漏風險**：智慧電錶記錄的即時用電量與時間，容易還原出企業的生產排程與營運機密；
2. **承諾電量與實際交付偏差**：再生能源發電具間歇性，事前承諾交易量與事後實際電力量測常存在偏差；
3. **交易公平性與責任追溯**：DSO 結算時若發生爭議，缺乏不可否認且具法律效力的責任歸屬機制；
4. **既有文獻局限**：現有區塊鏈電力交易方案多半僅能滿足隱私或智慧合約單一面向，缺乏兼顧隱私、責任追溯與自動清算的整合架構。

本研究結合三大關鍵密碼學與分散式技術：
1. **零知識證明（Zero-Knowledge Proof, ZKP）**：採用 Zcash 的 zk-SNARKs 技術，在完全隱藏具體用電度數與敏感商業資訊的前提下，向區塊鏈證明電量計算符合帳本規則；zk-SNARKs 證明尺寸小且驗證快速，極適合鏈上驗證；
2. **身分代理簽章（Identity-Based Proxy Signature, IBPS）**：用以約束 DSO 的結算權限，確保簽章權力受憑證限制，並具備事後不可否認與身分追溯性；
3. **區塊鏈與智慧合約自動結算**：交易紀錄經加密後存入鏈上，當 DSO 提交的零知識證明經智慧合約驗證無誤後，系統自動觸發撥款結算，杜絕人為舞弊。

系統實體架構分為三層：
- **信任與金鑰管理層**：由金鑰分發中心（KDC）負責系統初始化與產生公私鑰；KDC 完成初始化後即退出常態交易，僅在發生爭議時介入揭露惡意匿真實身分；
- **市場運作層**：包含產銷者、消費者與 DSO。各端配置智慧電錶回報實際發電與用電，由 DSO 清算並產出零知識證明；
- **區塊鏈結算層**：智慧合約驗證零知識證明後自動完成代幣清算與撥款。

本研究兼顧交易隱私性、可驗證性、不可偽造性與責任可追溯性，並將於後續進行電路層面的安全性證明。以上是我的報告，謝謝大家！

## 🧹 論文三：多策略資料前處理之研究：結合特徵選取、樣本選取與重取樣方法

**【大會司儀】**：謝謝歐陽教授。接下來歡迎下一位發表者——林玉慧同學，發表主題為「多策略資料前處理之研究：結合特徵選取、樣本選取與重取樣方法」。請林同學！

**【發表者 林玉慧】**：歐陽教授好、各位同學好，我是資管碩二的林玉慧，我的指導教授是蔡志豐博士。我的論文題目是「多策略資料前處理之研究：結合特徵選取、樣本選取與重取樣方法」。

隨著資訊科技與網路快速發展，各領域資料皆呈現爆炸性成長。然而現實生活中的原始資料充斥雜訊、冗餘特徵以及類別不平衡問題。若直接將原始資料投入模型訓練，將嚴重劣化模型學習效果與預測準確度。因此在資料探勘流程中，資料前處理是決定成敗的關鍵步驟。

目前多數文獻著重於單一前處理方法（例如單獨做特徵選取或單獨做樣本過濾），且多數研究缺乏跨領域、多維度的系統性比較。本研究旨在探討：
1. 單一特徵選取與樣本選取能否顯著提升分類效能？
2. 平行式整合（Ensemble）是否優於單一方法？
3. 序列式混合策略（先特徵選取再樣本選取，或先樣本選取再特徵選取）對效能與穩定性的影響？
4. 進一步結合重取樣（Resampling）技術以應對類別不平衡問題。

實驗設計分為兩大階段：
- **實驗一（特徵與樣本選取之平行與序列整合）**：
  - 資料集：精選 20 個涵蓋十位數、百位數、千位數至萬位數維度的跨領域標準資料集（各維度區間 5 個）；
  - 特徵選取演算法：卡方檢定（Chi-square/CFS）、基因演算法（GA）與互資訊量（Mutual Information, MI）；
  - 樣本選取演算法：凝結最近鄰（CNN）、編輯最近鄰（ENN）與 GA；
  - 平行式整合：採用集合運算（交集、聯集、多重交集）；
  - 分類器：Random Forest、SVM、Gradient Boosting，皆進行多組超參數調校並採五折交叉驗證；
  - 評估指標：AUC 與 F1-score。

實驗一（共 43 組方法組合）的核心發現：
1. **特徵選取平行多重交集效果最佳**：CFS、MI 與 GA 的多重交集在三個分類器中均獲得最高平均效能，相較 Baseline 達統計顯著差異，且特徵精簡率高，兼具特徵壓縮與效能提升；
2. **樣本選取容易造成資訊過度流失**：單純樣本選取或序列式混合策略（無論先特徵後樣本，或先樣本後特徵），多數表現甚至不如 Baseline，原因在於過度刪除邊界樣本導致可用資訊匱乏。

後續實驗二將針對類別不平衡資料，結合 SMOTE 等重取樣技術與實驗一產出的最佳特徵選取策略，驗證互補加成效果。以上是我的報告，謝謝大家！

## 🖼️ 論文四：基於半監督學習之多標籤影像分類研究

**【大會司儀】**：謝謝歐陽教授。接下來歡迎下一位發表者，發表主題為「基於半監督學習之多標籤影像分類研究」。請發表同學！

**【發表者 (指導：蔡志豐)】**：歐陽教授好、各位老師同學大家好，我的指導教授是蔡志豐博士。今天我要報告的主題是基於半監督學習之多標籤影像分類研究。

電腦視覺在智慧醫療、自駕車等領域應用廣泛。然而影像資料標註成本極為昂貴，因此半監督學習成為顯學。本研究聚焦於難度更高的「多標籤影像分類（Multi-Label Image Classification）」——一張圖片中可能同時包含多個類別（如同時出現貓、狗與沙發）。

多標籤半監督分類面臨幾大難點：
1. 正負樣本極度不均衡：以 80 個類別為例，一張圖片通常僅有 2-3 個正類別，其餘 70 多個皆為負樣本；
2. 偽標籤雜訊傳遞：錯誤的未標籤預測會嚴重干擾模型更新；
3. 固定門檻難以適應各類別分佈。

本研究提出 CMCL（Class-specific Margin Contrastive Learning）半監督框架：
1. **Teacher-Student 雙架構**：以 Student 模型學習困難樣本，以 Teacher 模型動態維護類別特徵中心；
2. **非對稱損失（Asymmetric Loss, ASL）**：針對大量簡單負樣本設定動態衰減因子，有效過濾簡單負樣本對梯度的干擾；
3. **類別自適應雙門檻（Class-Specific Dual Threshold）**：為每個類別獨立動態計算正類門檻與負類門檻，落於區間內的模糊預測不予硬切；
4. **類別原型對比學習（Prototype Contrastive Learning）**：建立各類別的理想特徵原型，將具高信心的偽標籤特徵向原型拉近，提升分類邊界的穩健度。

實驗在標準多標籤資料集上驗證，消融實驗證實類別自適應門檻與原型對比學習能顯著提升多標籤檢測之 mAP。以上是我的報告，謝謝大家！

## 📈 論文五：Sequential TAG 條件式格蘭傑因果圖與拓撲自適應圖卷積於臺灣股市投資組合建構之應用

**【大會司儀】**：謝謝歐陽教授。接下來歡迎本場次最後一位發表者——許紫薇同學，發表主題為「Sequential TAG 條件式格蘭傑因果圖與拓撲自適應圖卷積於臺灣股市投資組合建構之應用」。請許同學！

**【發表者 許紫薇】**：各位老師、同學大家好，我是許紫薇。我今天報告的論文題目是「Sequential TAG：條件式格蘭傑因果圖與拓撲自適應圖卷積於臺灣股市投資組合建構之應用」。

傳統股價預測多使用 ARIMA 或 LSTM 等時間序列模型，近年圖神經網路（GNN）盛行，學者開始引入產業關聯或持股網路等靜態圖結構來輔助預測。然而靜態圖缺乏時效性；若以交易量或報酬率的皮爾森相關係數建構動態圖，又存在「同步且雙向」的缺陷，無法辨別哪一檔股票對另一檔股票具有「前瞻預測價值」。

為了解決這個問題，本研究引入「條件式格蘭傑因果檢驗（Conditional Granger Causality Test）」與「拓撲自適應圖卷積網路（Topology Adaptive Graph Convolutional Network, TGCN）」：
1. **條件式格蘭傑因果關聯**：傳統雙變數格蘭傑檢驗容易因共同市場趨勢而產生偽因果（Spurious Causality）。本研究在受限與非受限模型中納入 Fama-French 五因子與產業報酬因子作為條件控制，唯有在排除市場整體因子影響後預測誤差仍顯著降低者，才確立其前瞻格蘭傑因果關聯；
2. **克服 GNN 過度平滑（Over-smoothing）問題**：傳統 GCN 堆疊多層以捕捉長距離依賴時，鄰接矩陣連乘會導致節點表徵指數趨同（過度平滑）。TGCN 採用多階可調距離的加法機制，無須堆疊多層即可直接聚合不同跳數（Hop）的鄰居資訊，保留節點獨特性；
3. **整體預測與投資組合架構**：
   - 使用 GRU 提取個股時序狀態；
   - 利用 TGCN 依據條件式格蘭傑因果圖聚合前瞻個股資訊；
   - 透過 MLP 預測次日對數報酬率；
   - 採滾動視窗（Rolling Window，3 個月訓練、1 個月驗證、1 個月評估）進行穩健性測試；
   - 依預測報酬率挑選 Top-K 股票建構投資組合，評估年化報酬率、夏普比率（Sharpe Ratio）與 NDCG。

實驗結果顯示，引入條件式格蘭傑因果與 TGCN 後，相較於傳統皮爾森關聯圖與無圖模型，方向預測準確率提升約 10%，夏普比率亦有顯著改善。以上是我的報告，謝謝大家！

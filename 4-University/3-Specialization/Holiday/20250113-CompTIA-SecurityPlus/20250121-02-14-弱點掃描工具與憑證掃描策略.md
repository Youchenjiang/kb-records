## 🔑 重點提要 (Key Takeaways)

1. **憑證掃描之必要性**：非憑證掃描只能看到表面服務 Banner；提供特定權限憑證才能真正檢查 Windows 登錄檔或 Linux 套件套裝有無修補重大漏洞。
2. **False Negative 最危險**：False Positive 只是浪費工時人工核實；False Negative 則是漏洞真實存在卻未被檢出，給予管理員虛假安全感。

## 🛡️ 弱點掃描工具、憑證掃描策略與代理程式評估表

| 核心考點與維度 | 技術原理與協定運作機制 | 業界安全最佳實踐與防禦控制項 | 認證考試應試陷阱與排障關鍵 |
| :--- | :--- | :--- | :--- |
| **非憑證式掃描（Unauthenticated Scanning）** | 從外部黑箱視角透過網路通訊埠探測系統，模擬未獲授權之外部駭客攻擊視角 | 僅能發現對外開放 Port 之表面漏洞與未遮蔽之服務 Banner，無法深入主機內部檔案與登錄表 | 掃描開銷較低且無需特權帳號，但誤報率高且漏報深層系統與本機應用程式弱點 |
| **憑證式掃描（Credentialed / Authenticated Scanning）** | 提供具備本地管理員權限之帳號密碼或 SSH 金鑰登入靶機，全面檢查本機登錄檔、修補缺失與內部組態 | 精確檢測本機安裝之第三方軟體版本與本地權限提升（Privilege Escalation）漏洞，誤報率極低 | 必須嚴格保護掃描專用特權帳號，採用專用帳密並限制僅能自掃描器 IP 發起連線 |
| **無代理掃描 vs. 代理程式掃描（Agent-based）** | 網路無代理掃描受限於防火牆阻隔與掃描排程窗口；Agent 輕量安裝於端點，隨時回傳本地安全態勢 | Agent 掃描不受遠端辦公（WFH）不在公司內網之限制，且無需在內網大量掃描引發網路頻寬衝擊 | 主流商業工具（Tenable Nessus, Qualys, Rapid7 InsightVM）全面支援混合式部署架構 |

- **本單元核心綜述與實務指引**：CompTIA Security+ SY0-701 考核重心在於將理論原則（如縱深防禦、最小權限與 CIA 三要素）無縫轉化為具體的系統配置與威脅處置作業流程。考生在面對複雜案例題時，應始終優先識別資產邊界與潛在威脅向量，並依據標準控制項架構採取最適切之技術或管理防禦措施。

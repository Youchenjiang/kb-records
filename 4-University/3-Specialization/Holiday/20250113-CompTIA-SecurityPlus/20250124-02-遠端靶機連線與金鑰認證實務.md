
## 🔑 重點提要 (Key Takeaways)

1. **原廠實驗室實操價值**：CompTIA Security+ 包含實作題（PBQs），必須親自在終端機輸入指令完成配置，不可僅靠紙上談兵。
2. **禁用 SSH 密碼登入**：生產環境應全面停用 PasswordAuthentication，強制改用 Ed25519 或 RSA 4096 憑證私鑰登入。

## 🛡️ 遠端靶機連線安全、SSH 金鑰認證與堡壘機實務表

| 核心考點與維度 | 技術原理與協定運作機制 | 業界安全最佳實踐與防禦控制項 | 認證考試應試陷阱與排障關鍵 |
| :--- | :--- | :--- | :--- |
| **SSH 安全組態強化與金鑰認證** | 全面停用不安全密碼登入（`PasswordAuthentication no`），強制使用 Ed25519 或 RSA-4096 非對稱金鑰認證 | 禁止 root 帳號直接遠端登入（`PermitRootLogin no`），必須以一般帳號登入後透過 `sudo` 提權並記錄日誌 | 變更預設 22 通訊埠，能有效減少 90% 以上網際網路盲目自動化殭屍掃描雜訊 |
| **跳板機 / 堡壘機（Bastion Host）實務架構** | 位於公網與內網隔離區之間之唯一受控存取節點；所有工程師存取內部生產伺服器必須強制先登入跳板機 | 跳板機啟用高強度 MFA，並全程記錄操作終端之所有輸入指令與螢幕畫面影音回放（Session Recording） | 嚴格限制跳板機自身外發連線，定期審計金鑰授權清單（`authorized_keys`）防範未授權後門 |
| **RDP 遠端桌面協定防護** | 啟用網路層級驗證（NLA, Network Level Authentication），在建立完整圖形工作階段前先強制驗證身分 | 切勿將 RDP 3389 直接暴露於公網，應強制要求先連線 VPN 或透過 RD Gateway 反向代理存取 | 限制連線閒置超時時間，並設定帳號登入失敗暫時鎖定防範暴力破解 |

- **本單元核心綜述與實務指引**：CompTIA Security+ SY0-701 考核重心在於將理論原則（如縱深防禦、最小權限與 CIA 三要素）無縫轉化為具體的系統配置與威脅處置作業流程。考生在面對複雜案例題時，應始終優先識別資產邊界與潛在威脅向量，並依據標準控制項架構採取最適切之技術或管理防禦措施。

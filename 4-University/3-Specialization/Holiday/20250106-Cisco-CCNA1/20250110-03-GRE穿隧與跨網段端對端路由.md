## 🔑 重點提要 (Key Takeaways)

1. **Underlay 路由是先決條件**：Tunnel 終點實體 IP（tunnel destination）若無法透過公網路由 Ping 通，Tunnel 介面絕對無法 Up。
2. **GRE 封裝開銷**：GRE 會額外增加 24 位元組標頭（20-byte IP + 4-byte GRE），實務上須注意調整 MTU 與 MSS 防止封包碎片化。

## 🛠️ GRE 通用路由穿隧配置步驟、MTU 碎片化與 Underlay 連通性檢驗表

| 穿隧工程階段 | Cisco IOS 介面設定指令範例 | 封包封裝格式與協定標頭開銷 | 網路效能考量與排障重點 |
| :--- | :--- | :--- | :--- |
| **Underlay 基礎路由連通** | 穿隧建立之前提：兩端實體路由器之公網出口介面 IP 必須能互通（可透過 Ping 驗證） | 若底層公網路由中斷，Tunnel 介面 Protocol 將瞬間轉為 Down，上層虛擬連線隨之瓦解 | `ping <對端公網實體IP>`：確認底層傳輸通道無防火牆阻擋 GRE 協定封包 |
| **Tunnel 虛擬介面配置** | `Router(config)# interface Tunnel 0`<br/>`Router(config-if)# ip address 172.16.1.1 255.255.255.0`<br/>`Router(config-if)# tunnel source Serial0/0/0`<br/>`Router(config-if)# tunnel destination 203.0.113.2` | 封裝層次：原始內部 IP 封包 $\to$ GRE 標頭（4 位元組，IP 協定號 **47**） $\to$ 外部公網 IP 標頭（20 位元組） | GRE 本身為明文穿隧（Clear-text），不提供加密；實務常外加 IPsec 封裝實現站台對站台 VPN |
| **MTU 碎片化與路徑繞送** | `Router(config-if)# ip mtu 1400`<br/>`Router(config-if)# ip tcp adjust-mss 1360`<br/>`Router(config)# ip route 192.168.20.0 255.255.255.0 Tunnel 0` | 額外 24 位元組封裝可能導致超過標準 1500 MTU 觸發封包碎片化（Fragmentation）降低轉發效能 | 設定 `ip tcp adjust-mss` 能主動調整 TCP 三方交握 SYN 封包，預先防止巨型封包被中途丟棄 |
